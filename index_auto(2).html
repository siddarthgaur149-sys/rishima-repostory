So, what is XML?

eXtensible

You invent your own tags: <book>, <student>, anything.

Markup Language

Plain text wrapped in tags that give it meaning.

W3C Standard

Recommended by the W3C in 1998.

Platform-free

Plain text, so it works on every OS and every program.

XML vs HTML




XML
Stores and carries data
You make up the tags
Strict: every rule enforced
Case-sensitive


HTML
Displays data
Tags are predefined
Forgiving of mistakes
Not case-sensitive
